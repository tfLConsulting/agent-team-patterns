## Observations recorded

### 1. Memory graduation with explicit, bidirectional thresholds

Hot memory stays under cap reliably when graduation rules are stated as thresholds, not narrative. Each transition has a named trigger — dormant-for-N graduates out, influencing routing again pulls back in, project-closed plus dormant-window archives. Sharpening of `three-tier-memory.md`, not a replacement: the contribution is making the conditions explicit and bidirectional, not the tier structure itself.

### 2. The coach must not read other agents' memory bodies

A coach that reads agent memory anchors on each agent's self-narrative and loses the outside-context property that justifies the coach role at all. Briefs and journals only. Cheap to adopt, structurally important. Worth auditing our own coach against.

### 3. Coach framework versioned, self-reflection coda at end of every review

A coach review that doesn't ask "are these dimensions still earning their keep?" lets the framework calcify silently. A short self-reflective coda at the bottom of every review catches dimension obsolescence.

### 4. Anti-patterns codified from named incidents

Two relevant to a router-with-specialists topology: (a) lead-as-implementer drift — verification slides into the lead doing the repair, recorded explicitly if unavoidable; (b) delegated workers editing shared lead-owned state — forbidden when the lead retains synthesis ownership. The discipline is codifying *the first* occurrence, not waiting for a pattern.

### 5. Parked branches with explicit named wake conditions

Threads end one of three ways: closed (eventually archived), parked with a *named* wake condition, or refused with the refusal logged. Each parked branch is one line plus a pointer to a longer file. Prevents zombie threads while keeping reactivation cheap. We have approximately this structure for our flagged-not-fixed items but lack the explicit wake condition — that's the upgrade.

### 6. Cadence-slippage codified rather than fudged

Stated coach cadence vs. observed cadence will diverge. An explicit one-deferral rule (directed work can defer once; next session must run coach) makes slippage auditable rather than invisible.

### 7. Specification quality of dispatched assignments

Every assignment names allowed behaviour, an enumerated list of forbidden non-claims, exact public names, tripwires, and gate set. Plausibly the highest-leverage discipline for maintaining coherent output. We do a weaker version implicitly.
