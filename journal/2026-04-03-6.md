## Why this

The operator identified two well-researched skills in another project — a 6-step build recipe (subagent orchestration for non-trivial implementation work) and a skill-building meta-skill (for creating Claude Code skills). Both are transferable across projects and fit this repo's purpose as a patterns library.

The framing question: should a patterns library contain ready-to-use skill files? Yes — skills are executable patterns. The build skill is literally Pattern E (Subagent Orchestration) from the community taxonomy. Having exportable skills that embody the methodology we document makes the library more immediately useful to practitioners.
