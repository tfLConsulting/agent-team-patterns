# Reuse the earlier work selectively

The earlier library describes an agent-team application. Its mechanisms can still serve the broader cycle. Existing evidence claims belong to their original documents and are not new validation of this synthesis.

| Earlier pattern | Principle worth retaining | Reconsider locally |
|---|---|---|
| [Three-tier memory](../methodology/three-tier-memory.md) | Small current context with retrievable history | Need for per-role files and fixed size thresholds |
| [File coordination](../methodology/file-based-coordination.md) | Explicit ownership and handoffs | Whether a database or single record is simpler |
| [Role design](../methodology/role-design.md), [brief anatomy](../methodology/brief-anatomy.md) | Authority, responsibilities, useful context | Whether standing agents are needed at all |
| [Self-modifying briefs](../methodology/self-modifying-briefs.md) | Improve instructions from evidence | Who may change rules and whether active contracts are protected |
| [Writing for AI](../methodology/writing-for-ai.md) | Clear, economical, retrievable instructions | Current model/runtime behavior and applicability of old findings |
| [Learning from practice](../methodology/learning-from-practice.md) | Evidence grades and disconfirming observations | Cost of formal experiments for occasional work |
| [Investigation threads](../methodology/investigation-threads.md), [load-bearing beliefs](../methodology/load-bearing-beliefs.md) | Bound uncertainty and test premises | When research should stop or change direction |
| [Codification ladder](../methodology/codification-ladder.md) | Use the lightest durable mechanism | Whether a repeated practice still solves a live problem |
| [Session transaction](../methodology/session-transaction-protocol.md) | Detect interruption and reconcile intent/artifacts | Runtime-specific session machinery |
| [Measurement skepticism](../methodology/measurement-skepticism.md) | Check the instrument before interpreting its output | Current populations, definitions, and calibration |
| [Coaching](../methodology/coaching-framework.md) | Inspect the process as well as its outputs | Need for a standing coach and fixed review cadence |
| [Discipline processes](../methodology/discipline-processes.md), [team guide](../methodology/agent-team-guide.md) | Explicit workflow and coordination where justified | Mandatory teams, delegation, and platform assumptions |
| [Build skill](../skills/build/SKILL.md) | Separate investigation, implementation, and verification | Fixed subagent stages and review cost |
| [Skill-building skill](../skills/skill-building/SKILL.md) | Package reusable instructions with progressive context | Current vendor integration and discovery rules |

Keep historical investigations as evidence of questions and methods, not as a current capability registry. Historical journals and memories explain earlier choices; the current repo instructions and work record govern new work.
