# Working on Agent Team Patterns

This is a public design library, not an installed agent framework. Read README.md,
work/README.md, and the relevant principle/application before changing content.
CLAUDE.md points here; historical role briefs and commands do not govern normal work.

Use a manual planning → execution → disposition cycle. Record a bounded objective,
acceptance evidence, actual result, remaining uncertainty, and next useful action in
work/. Keep direction decisions distinct from implementation and from publication.
On plain `execute-dev N`, follow applications/manual.md using work/ as the canonical
record (default N=1). Do the work, not just selection; report actual attempt and
acceptance counts. If no eligible work remains, report that rather than inventing work.
Do not install schedules or a live queue for this infrequently updated library.
Subagents and independent review are optional choices justified by the task; do not
claim independent review when only self-review occurred.

Write principles with tradeoffs, alternatives, failure modes, and evidence limits.
Examples must be fictional and self-contained. Prefer small working code with
meaningful tests to a general framework. Keep platform-neutral workflow text separate
from dated vendor capability notes. Check links and run relevant example tests.
Preserve unrelated edits and historical evidence.

Private reference repositories are read-only background evidence, never copy sources.
Do not publish their names, paths, identifiers, quotes, metrics, business facts,
task records, code, or distinctive operational configurations. Derive general ideas
in fresh language and use invented examples. Inspect every added/changed file,
including untracked files, for accidental disclosure. Do not put private provenance
in a public journal or commit message. Unknown evidence stays unknown.

Before ending, reconcile work/ with actual checks and disposition. A local change
is not user acceptance, a commit is not publication, and passing tests do not prove
business benefit. Do not commit or push unless requested.
